How the odds are made

Every number on this board comes from simulate.py, a Monte Carlo engine that plays the entire 2026 tournament 100,000 times — the same headline number Nate Silver's PELE model uses.

1 · Ratings. Each team carries an Elo-style rating (a static pre-tournament snapshot, editable in data/teams.json). Hosts get a home-advantage bonus — Mexico's is the largest, reflecting the Azteca's altitude, with a smaller edge for the US and Canada and a reduced bonus in knockouts.

2 · Matches. The Elo gap sets each side's expected goals, and scorelines are drawn from independent Poisson distributions:

μ_A = 1.30 · exp(+0.0045 · ΔElo / 2)
μ_B = 1.30 · exp(−0.0045 · ΔElo / 2)
goals ~ Poisson(μ)

3 · Format. All 72 group games are simulated with FIFA's 2026 tiebreakers (points → head-to-head → goal difference → goals scored), the eight best third-place teams join the 24 group winners and runners-up, and a 32-team single-elimination bracket plays out to the final. Drawn knockout games go to extra time and penalties, modeled with a dampened Elo edge.

4 · Odds. Counting how often each team lifts the trophy across all runs gives a probability, and fair odds are simply its inverse (decimal = 1/p). One honest simplification: the real third-place bracket allocation depends on which 8 groups produce qualifying thirds (495 combinations), so qualifying thirds are assigned to bracket slots randomly each run.

Run it yourself:

pip install numpy
python simulate.py -n 100000        # full PELE-scale run (~1 min)
python simulate.py -n 20000 --seed 7 -o output/odds.json

No API keys required. To go further: live Elo from eloratings.net (free, no key), fixtures & squads from football-data.org (free key) or API-Football, and real market prices from The Odds API (free key) to compare against the model.
